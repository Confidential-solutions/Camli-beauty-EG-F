## 🤖 Guidelines for AI Agents

1. **Overlay & Panel Framing**:
   - Shared sheet, dialog, drawer, and popover components must use the `panel-frame` utility and safe-area panel offsets so open surfaces stay separated from the page and within the viewport.

2. **Routing Conventions**:
   - The project uses **TanStack Start file-based routing** in `src/routes/`.
   - Never create `src/pages/`, `src/routes/_app/`, or `app/layout.tsx`.
   - Never manually modify `src/routeTree.gen.ts`; it is auto-generated by the TanStack Router plugin during build / dev.

3. **Bilingual Support (i18n)**:
   - Always maintain translations for both English and Arabic.
   - When modifying UI text or forms, update `src/i18n/dictionary.ts` or corresponding localized objects.
   - Ensure components look correct in both RTL (`dir="rtl"`) and LTR (`dir="ltr"`).

4. **SEO & Metadata**:
   - When creating or modifying a route in `src/routes/`, always include the `seoHead()` export with appropriate title, description, canonical path, and keywords.

5. **Shopify Integration & Catalog Accuracy**:
   - Preserve real variant IDs in `src/data/products.ts` so cart checkout hand-off functions properly.
   - Use `useLiveShopifyCatalog()` and `resolveProduct()` to respect live stock and pricing from Shopify.
