# 🏛️ Architecture Documentation — Camli Beauty Egypt

This document details the architectural principles, component structure, state lifecycle, and design decisions powering the **Camli Beauty Egypt** e-commerce application.

---

## 1. High-Level System Architecture

The application is built on top of **TanStack Start** with **React 19** and **Vite 6**. It delivers a hybrid rendering model (SSR/SSG with client hydration) designed for speed, SEO excellence, and smooth micro-interactions.

```
┌─────────────────────────────────────────────────────────────┐
│                       Client Browser                        │
│   (React 19 Hydration • Language Context • Cart Store)      │
└──────────────┬──────────────────────────────▲───────────────┘
               │                              │
               ▼ HTTP / Navigation            │ Hydrated HTML / JSON
┌─────────────────────────────────────────────┴───────────────┐
│                    TanStack Start Server                    │
│   (Vite SSR Engine • File-based Router • Meta Tags)         │
└──────────────┬──────────────────────────────▲───────────────┘
               │                              │
               ▼                              │
┌─────────────────────────────────────────────┴───────────────┐
│                     External Services                       │
│   • Camli Shopify CDN (Product Images & Media Assets)       │
│   • Shopify Store Cart (/cart Hand-off)                     │
│   • Google Fonts (Amiri, Playfair, Inter)                   │
└─────────────────────────────────────────────────────────────┘
```

## 2. Directory Structure & Responsibilities

| Directory                | Purpose                                                                                                            |
| :----------------------- | :----------------------------------------------------------------------------------------------------------------- |
| `src/routes/`            | **File-Based Routes**: Defines URL hierarchy. Every `.tsx` file maps to an application route.                      |
| `src/components/layout/` | **Persistent Shell**: Components that form the site chrome (Header, Footer, CartDrawer, AuthModal).                |
| `src/components/shared/` | **Domain Modules**: Reusable customer-facing components (ProductCard, Catalog, HeroVideo, ChatWidget, Boundaries). |
| `src/components/ui/`     | **Design System Primitives**: Headless accessible components built on Radix UI, styled with Tailwind CSS v4.       |
| `src/data/`              | **Static & Seed Data**: Product details, Shopify variant IDs, and brand media URLs hosted on the Shopify CDN.      |
| `src/i18n/`              | **Translation Dictionaries**: Key-value translations and helpers for Arabic (`ar`) and English (`en`).             |
| `src/lib/`               | **Core Utilities**: Cart state manager, SEO meta builder, error capturing, and telemetry.                          |
| `src/app/`               | **Application Context**: React context providers for language, authentication, and global app state.               |

## 3. Routing & Route Tree Generation

TanStack Start utilizes a type-safe, file-based routing convention:

- **Root Layout** (`src/routes/__root.tsx`): Sets global meta tags, injects stylesheets, binds language providers, and renders the `<Header />`, `<Outlet />`, `<Footer />`, and `<CartDrawer />`.
- **Index Route** (`src/routes/index.tsx`): The store landing page (`/`).
- **Dynamic Product Route** (`src/routes/products.$handle.tsx`): Captures `$handle` URL parameter to display the specific product page (`/products/:handle`).
- **Route Manifest** (`src/routeTree.gen.ts`): Automatically generated by the TanStack Router Vite plugin. _This file should never be manually edited._

### Route Conventions Reference

```

├── __root.tsx              -> Global app shell & context wrapper
```

## 4. Internationalization (i18n) & RTL Engine

The application delivers an authentic bilingual experience for Egyptian and regional shoppers:

- **Supported Locales**: Arabic (`ar` — default in Egypt) and English (`en`).
- **Direction Switching**: The `dir` attribute on `<html>` dynamically toggles between `rtl` and `ltr`.
- **Localized Typography**:
  - Arabic: **Amiri** and **Cairo** for elegant Arabic calligraphy and legibility.
  - English: **Playfair Display** (editorial serif) and **Inter** (clean sans-serif).
- **Mirrored Layout**: CSS transforms, padding, margin, and drawer animations mirror automatically according to document direction.

## 5. SEO & Structured Data Architecture

Every page route exports a `head()` function utilizing the centralized `seoHead()` helper (`src/lib/seo.ts`):

- **Canonical URLs**: Generated based on route paths to avoid duplicate content penalties.
- **Social Tags**: OpenGraph (`og:title`, `og:description`, `og:image`, `og:type`) and Twitter cards (`summary_large_image`).
- **Core Beauty Keywords**: High-intent keywords targeting Sudanese Dilka, body scrubs, natural skincare, and body butters in Egypt.
- **JSON-LD Schema**:
  - `Organization` & `WebSite` schema on root.
  - `Product` schema on individual product pages including real variant prices in EGP and availability status.
  - `BreadcrumbList` schema representing site navigation hierarchy.

## 6. Cart Lifecycle & Shopify Hand-off

```
[User clicks "Add to Cart"]
            │
            ▼
[Cart State Updated (src/lib/cart.ts)]
            │
            ▼
[Cart Drawer Opens (Side sheet / Bottom modal on mobile)]
            │
            ▼
[User clicks "Checkout"]
            │
            ▼
[Direct Redirect to Shopify Checkout: camlibeautyeg.com/cart/{variant_id}:{qty}]
```

1. **State Persistence**: The client-side cart stores items in `localStorage` keyed by Shopify variant ID.
2. **Shopify Hand-off**: When the shopper proceeds to checkout, the cart constructs the official Shopify checkout URL format:
   `https://www.camlibeautyeg.com/cart/{variant_id}:{quantity}?note=...`
   This ensures seamless inventory tracking, payment gateway handling (InstaPay, Credit Cards, Cash on Delivery), and Egyptian shipping zones managed inside Shopify.

## 7. UI Components & Safe-Area Panel Utilities

All popovers, dropdown menus, sheets, and dialogs follow strict viewport safety rules:

- Primitives from **Radix UI** ensure full keyboard accessibility (WAI-ARIA).
- Shared components leverage the `panel-frame` utility to maintain padding and prevent overlays from clipping off-screen on mobile devices or overflowing the viewport edges.
